# Military Logistics Platform

An AI-powered logistics platform for remote and high-altitude Army posts.

## Project Objective

The system predicts future supply requirements, monitors inventory, analyzes terrain and weather conditions, and helps plan timely transportation.

## Main Modules

1. Demand Forecasting
2. Inventory Tracking
3. GIS-Based Route Planning
4. Weather-Aware Planning
5. Transportation Planner
6. Dashboard and Alerts

## Technology Stack

- Python
- FastAPI
- Machine Learning
- SQLite / PostgreSQL
- NetworkX
- React / Vite
- MapLibre
- Recharts

## Project Structure

- `backend` – API and database
- `ml` – Demand forecasting and ML models
- `routingg` – Route planning
- `web` – Dashboard
- `edge` – Offline data and synchronization
- `ops` – Deployment and operations
- `contracts` – Shared API/data contracts
- `data` – Sample and synthetic datasets
